# Visit the Client Gateway

Open the hostname configured in [Deploy the Client Gateway](deploy-the-client-gateway.md) section on a browser to visit the deployed Client GW. Use the appropriate protocol `http` or `https` based on whether TLS is enabled.

`http(s)://YOUR_APP_HOSTENAME/` is available for the application UI.

`http(s)://YOUR_APP_HOSTENAME/docs` is available for the api documentation.
