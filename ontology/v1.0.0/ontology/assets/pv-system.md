# Assets Domain: PhotovoltaicUnit

---

## int:PhotovoltaicUnit

**IRI:** `int:PhotovoltaicUnit`

**Subclass of:** [`int:Asset`](asset.md#intasset), `cim:PhotovoltaicUnit`

**Standard mapping:** `cim:PhotovoltaicUnit`, `IEC 61850 MMXU`

A photovoltaic solar generation system including panels and inverter. Inherits all properties of `int:Asset`. Carries static installation parameters as datatype properties. Dynamic measurements are expressed as `sosa:Observation` instances.

### Datatype Properties

| Property | IRI | Range | Description |
|----------|-----|-------|-------------|
| peakPower | `cim:maxP` | `xsd:float` | Installed peak power in kilowatts-peak (kWp). |
| panelAzimuth | `int:panelAzimuth` | `xsd:float` | Panel azimuth angle in decimal degrees from north (0–360). |
| tiltAngle | `int:tiltAngle` | `xsd:float` | Panel tilt angle in decimal degrees from horizontal (0–90). |
| altitude | `int:altitude` | `xsd:float` | Installation altitude in metres above sea level. |
| mountingType | `int:mountingType` | `owl:oneOf` | Panel mounting configuration. |
| inverterType | `int:inverterType` | `xsd:string` | Inverter make and model string. |
| numberOfMPPTs | `int:numberOfMPPTs` | `xsd:integer` | Number of maximum power point tracking (MPPT) channels on the inverter. |

### Enumeration Values

#### int:mountingType

| Value | Description |
|-------|-------------|
| `Fixed` | Fixed-angle mounting. |
| `SingleAxisTracker` | Single-axis solar tracking. |
| `DualAxisTracker` | Dual-axis solar tracking. |
