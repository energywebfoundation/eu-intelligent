# Changelog

Notable changes to the INTELLIGENT ontology. Versioning follows the rules in the ontology overview (`ontology/v1.1.0/docs/overview.md`, Versioning section): new classes or properties increment MINOR.

## [1.1.0] - 2026-11-20

### Added

- Certification domain with `int:GreenProof`, defined in `ontology/v1.1.0/ontology/certification/green-proof.md`. Source: the GreenProofs tab of the shared working spreadsheet (details provided by GSY and EW).
- ADR-017 in `ontology/v1.1.0/docs/design-decisions.md` and open questions OQ-013 to OQ-023 in `ontology/v1.1.0/ontology/open-questions.md`.
- GreenProof entries in the v1.1.0 overview, glossary, standard mappings and ER diagram.
- Reference file `ontology/v1.1.0/reference-files/INTELLIGENT_Ontology_PILOT_SHARED_20261120.xlsx`: a full export of the shared working spreadsheet. The ten v1.0.0 reference files are carried over unchanged.

### Changed

- No existing class, property or enumeration was modified. `ontology/v1.0.0/` is unchanged.

## [1.0.0]

- Initial ontology, in `ontology/v1.0.0/`.
